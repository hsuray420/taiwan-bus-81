# 台灣公車模擬器 - 統聯客運 81路 (Taiwan Bus Simulator 81)

台灣台中市公車 **81路**（統聯客運／臺灣金龍 KINGLONG KL6112U1 11.2m 短軸四期）網頁版駕駛模擬遊戲。

---

## 🌟 核心還原特色

### 1. KINGLONG KL6112U1 短軸四期低地板公車 (11.2m x 2.5m x 3.2m)
* **車型基準**：Cummins ISBe4+250B 四期引擎、6,692.4cc、250hp、5.3m 軸距、手排變速系統。
* **經典外觀**：統聯客運招牌青蘋果綠塗裝 (`#148c3a`)、白色拉花飾條、金龍車頭橫柵與大曲面前擋風玻璃。
* **動態 LED 看板**：車頭與車尾真實發光點陣 LED，顯示「`81 經 公益路 臺中車站`」。
* **通透座艙與內裝**：
  * 右側安裝台灣專用 **寶錄電子 (Baolu) IC 卡刷卡機**（綠色液晶動態跳字）。
  * 走道兩側黃色安全立柱，每根立柱均配有 **紅色下車鈴按鈕**（按下會發光）。
  * 人體工學座椅與深藍色博愛座。
* **左駕駕駛室與物理機關**：
  * 駕駛座在左側，右側為投幣箱、寶錄刷卡機與乘客上車門。
  * 手排檔桿、雙氣壓表、駕駛開關面板與黃色氣壓手煞車。
  * 前折疊門與中雙開外滑門獨立氣動開閉動畫；到站後自動開門，乘客自動上下車。
  * 六輪轉動、前輪轉向、駕駛座方向盤隨動旋轉。
  * 車體煞車點頭與過彎內輪差懸吊傾斜。

### 2. 靈魂音效系統 (Web Audio API 原生合成)
* **悠遊卡 / 一卡通「BBB」刷卡聲**：
  * 普通卡：清脆單音 `1960Hz`「嗶~」（提示市民 10 公里免費）。
  * 學生票 / 愛心票：快速三連音「嗶、嗶、嗶」。
* **下車鈴**：經典雙音調「叮咚~」（E6 降至 C6）。
* **氣剎排氣聲**：大巴急煞與放鬆踏板時的壓縮空氣「嘶——哧！」排氣聲。
* **柴油引擎聲**：隨行駛時速與油門深度動態調頻的柴油重低音。
* **氣動車門與警示音**：開門排氣與關門前「嗶、嗶」安全提示音。
* **81路到站播音**：國台客英到站廣播。

### 3. 台中市 81路 真實路線與街景
* **完整固定站序**：目前以交通局／TDX 衍生的去程資料建立 `統聯轉運站(站內)` 至 `太原六號橋(太原路)` 的 53 站資料集；每站都會觸發停靠事件。一般站使用低負載站牌，大站與轉運節點使用候車亭。
* **資料差異註記**：維基百科目前頁面列出的去程站數與 TDX／Busnow 資料集不同；正式發布前要鎖定同一個日期版本，才能宣稱與官方現行站序逐站完全一致。
* **台灣特色道路標線**：
  * 中央雙黃實線、路面白虛線。
  * 站牌前紅色標線與路面彩繪 **「公車停靠區」** 大字。
  * 十字路口斑馬線與 **黃色機車停等區**。
  * 台灣專屬 **小綠人行人倒數號誌燈**。
  * 騎樓街景建築與經典店家招牌（7-ELEVEN、全家便利店、50嵐珍奶、台中太陽餅老店）。

## 🧭 真實化重構方向（2026-11-07）

### 目標

本專案的體驗定位改為「81 路公車司機駕駛體驗」，不是乘客操作介面。玩家只負責駕駛、煞車、方向、車門與視角；刷卡、下車鈴、乘客上下車和車內提示音由乘客與車輛事件自動發生。

### 固定路線與低終端負載方案

81 路是固定路線，因此長期最適合改成「高品質預渲染路線 + 輕量互動控制」：

1. 以高品質 3D 引擎預先製作路線與車內畫面。
2. 依路段輸出影片或 360 度素材，瀏覽器只負責硬體解碼、播放和事件時間軸。
3. 以輕量 JavaScript 控制速度、車門、站點、廣播、刷卡和下車鈴事件。
4. 若日後仍要求完全自由的即時 3D，再評估 Unreal/Unity Pixel Streaming 等雲端 GPU + WebRTC；一般 GitHub Pages 或 Cloudflare Pages 不會替使用者計算 WebGL。

這種固定路線方案能同時提高街景真實度、降低電腦發熱，並保留司機操作感。預渲染影片不能提供完全自由的 3D 繞行視角，這是刻意的產品取捨。

### 目前優先實作

- 移除玩家手動刷卡、手動按下車鈴和乘客模式；改為乘客自動事件。
- 保留玩家的方向、油門、煞車、手煞車和鏡頭控制；站點車門與乘客流程自動處理。
- 車輛轉向時自動播放大型車轉彎警示蜂鳴器，並避免靜止時持續播放。
- 路線資料以臺中市政府交通局「台中Go」及 TDX 衍生站序為準，不再只顯示五個示意站。
- 聲音先以可追溯的仿真 fallback 實作；未取得授權或原始錄音前，不把網路影片音訊直接打包進專案，也不宣稱是「81 路原音」。

### 聲音真實性規則

轉彎蜂鳴器、刷卡音、車門氣壓聲、下車鈴和到站廣播必須分開驗證。若只有網路影片可聽見但沒有明確授權，程式只能使用標示為「仿真」的音效；收到可授權的 81 路錄音素材後，才替換成實錄並記錄來源、授權和檔案版本。
