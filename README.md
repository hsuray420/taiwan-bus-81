# 台灣公車模擬器 - 台中市公車 81路 (Taiwan Bus Simulator 81)

台灣台中市公車 **81路**（成運電能 EV BUS / EAL-5195 / 台灣標準左駕版）網頁版駕駛模擬遊戲。

---

## 🌟 核心還原特色

### 1. 成運電能 EV BUS 低底盤電動公車 (EAL-5195 專用塗裝與駕駛艙)
* **車型外觀**：科技白底色車身、車頂黑色烤漆飾帶、下側鮮明果綠幾何斜切飾條、車頭/車側高解析 `EAL-5195` 台灣電動大客車專屬牌號、斜體 `EV BUS`、`ZERO EMISSION` 零排放標語與充電插頭線路插畫。
* **輪廓側燈**：雙側下裙配置 10 組暖橘色輪廓標誌燈。
* **動態 LED 看板**：車頭與車尾真實發光點陣 LED，顯示「`81 經 公益路 臺中車站`」。
* **通透座艙與內裝**：
  * 仿木紋耐磨地板、深灰流線型一體化駕駛台（Molded Cockpit Pod）。
  * 方向盤下部配置弧形銀白色 U 型金屬飾條（Silver U-Trim Accent）。
  * 駕駛座左側 A 柱電子後視鏡監視螢幕、左側黃框車載主機（Telematics Terminal）。
  * 駕駛座右側配置 4 分割 CCTV 監控螢幕，即時監控前門、中門、車廂與車尾。
  * 右上方配置台灣公車經典圓形紅色「下站停車 ♿」燈號（隨下車鈴同步點亮）。
  * 台灣專用 **寶錄電子 (Baolu) IC 卡刷卡機**（綠色液晶動態跳字）。
  * 走道兩側黃色安全立柱，每根立柱均配有 **紅色下車鈴按鈕**（按下會發光）。
  * 人體工學座椅與深藍色博愛座。
* **全數位雙圓液晶儀表板 (Dual Digital LCD Cluster)**：
  * 左表：即時電量 `100% SOC`、電池溫度 `48°C`、動力狀態弧形綠色光條。
  * 右表：大型數位時速表、`km/h`、手排即時檔位 `GEAR: 1..5 / N / R`。
  * 頂部：左/右綠色轉向指示箭頭燈號（閃爍）、`READY` 綠燈、`(P)` 手煞車紅燈警示。
  * 底部：總里程計 `ODO: 12,842 km`、車號 `EAL-5195 MASTER`。

### 2. 靈魂音效系統 (Web Audio API + 使用者實錄)
* **真實轉彎段外部警告蜂鳴器**：使用使用者提供的台灣大巴實車錄音檔（`turn-signal.mp3`），在轉向（A/D 鍵）或開啟方向燈（Q/X 鍵）時無縫播放真實警示廣播與蜂鳴音。
* **悠遊卡 / 一卡通「BBB」刷卡聲**：
  * 普通卡：清脆單音 `1960Hz`「嗶~」（提示市民 10 公里免費）。
  * 學生票 / 愛心票：快速三連音「嗶、嗶、嗶」。
* **下車鈴**：經典雙音調「叮咚~」（E6 降至 C6），觸發車內下車鈴發光與右上方圓形紅色「下站停車」亮燈。
* **氣剎排氣聲**：大巴急煞與放鬆踏板時的壓縮空氣「嘶——哧！」排氣聲。
* **引擎與驅動聲浪**：依檔位、離合器、轉速與油門深度動態調頻的仿真聲浪。
* **氣動車門與警示音**：開門排氣與關門前「嗶、嗶」安全提示音。
* **81路到站播音**：國台客英到站廣播。
* **使用者原始行車錄音**：`assets/audio/user-video-reference.mp3` 由使用者提供的影片轉出，按 `V` 播放／暫停。

### 3. 台中市 81路 真實路線與街景
* **完整固定站序**：目前以交通局／TDX 衍生的去程資料建立 `統聯轉運站(站內)` 至 `太原六號橋(太原路)` 的 53 站資料集；每站都會觸發停靠事件。一般站使用低負載站牌，大站與轉運節點使用候車亭。
* **資料差異註記**：維基百科目前頁面列出的去程站數與 TDX／Busnow 資料集不同；正式發布前要鎖定同一個日期版本，才能宣稱與官方現行站序逐站完全一致。
* **台灣特色道路標線**：
  * 中央雙黃實線、路面白虛線。
  * 站牌前紅色標線與路面彩繪 **「公車停靠區」** 大字。
  * 十字路口斑馬線與 **黃色機車停等區**。
  * 台灣專屬 **小綠人行人倒數號誌燈**。
  * 騎樓街景建築與經典店家招牌（7-ELEVEN、全家便利店、50嵐珍奶、台中太陽餅老店）。

## 🎮 操作指南

| 鍵盤按鍵 | 功能說明 |
| :--- | :--- |
| **W** 或 **↑** | 前進加速 |
| **S** 或 **↓** | 煞車減速 / 倒車 |
| **Shift** | 踩住離合器 |
| **R** / **F** | 升檔 / 降檔 |
| **N** | 回空檔 |
| **A** / **D** 或 **←** / **→** | 方向盤左右轉向（具備大巴內輪差特性） |
| **Space** | 氣剎手煞車 |
| **1** | 開啟 / 關閉 **前門** |
| **2** | 開啟 / 關閉 **中門** |
| **C** | 切換視角（左駕駕駛室第一人稱 / 車外追蹤） |
| **H** | 按喇叭 |
| — | 乘客自動刷卡、按下車鈴與上下車；轉彎時自動播放大型車警示蜂鳴器 |

*手排起步：踩住 `Shift` → 按 `R` 入 1 檔 → 放開離合器並按 `W`。行進中請依速度升檔；拖檔會熄火，踩住離合器並按 `W` 可重新啟動。*

*行動裝置或平板亦可使用畫面上的虛擬按鈕與觸碰鍵盤進行遊戲；手排鍵盤控制目前以桌面駕駛為主。*

## 🧭 真實化重構方向（2026-11-07）

### 目標

本專案的體驗定位改為「81 路公車司機駕駛體驗」，不是乘客操作介面。玩家只負責駕駛、煞車、方向、車門與視角；刷卡、下車鈴、乘客上下車和車內提示音由乘客與車輛事件自動發生。

### 固定路線與低終端負載方案

81 路是固定路線，因此長期最適合改成「高品質預渲染路線 + 輕量互動控制」：

1. 以高品質 3D 引擎預先製作路線與車內畫面。
2. 依路段輸出影片或 360 度素材，瀏覽器只負責硬體解碼、播放和事件時間軸。
3. 以輕量 JavaScript 控制速度、車門、站點、廣播、刷卡和下車鈴事件。
4. 若日後仍要求完全自由的即時 3D，再評估 Unreal/Unity Pixel Streaming 等雲端 GPU + WebRTC；一般 GitHub Pages 或 Cloudflare Pages 不會替使用者計算 WebGL。

這種固定路線方案能同時提高街景真實度、降低電腦發熱，並保留司機操作感。預渲染影片不能提供完全自由的 3D 繞行視角，這是刻意的產品取捨。

### 目前優先實作

- 移除玩家手動刷卡、手動按下車鈴和乘客模式；改為乘客自動事件。
- 保留玩家的方向、油門、煞車、手煞車和鏡頭控制；站點車門與乘客流程自動處理。
- 車輛轉向時自動播放大型車轉彎警示蜂鳴器，並避免靜止時持續播放。
- 路線資料以臺中市政府交通局「台中Go」及 TDX 衍生站序為準，不再只顯示五個示意站。
- 聲音事件仍保留可追溯的仿真 fallback；使用者已明確授權自己的影片音訊轉檔，因此目前另外提供原始行車錄音播放，不把整段錄音錯切成車門、刷卡或下車鈴的假事件音效。

### 聲音真實性規則

轉彎蜂鳴器、刷卡音、車門氣壓聲、下車鈴和到站廣播必須分開驗證。若只有網路影片可聽見但沒有明確授權，程式只能使用標示為「仿真」的音效；本專案目前只把使用者明確說明為自己的影片轉檔，並記錄來源與格式。若要把其中某段替換成單一事件，還需要該事件的時間戳，避免錯誤剪輯。
