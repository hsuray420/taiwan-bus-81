# 台灣公車模擬器 - 統聯客運 81路 (Taiwan Bus Simulator 81)

1:1 台灣台中市公車 **81路**（統聯客運 DAEWOO 大宇 BS120CN 低底盤公車）網頁版駕駛模擬遊戲。

---

## 🌟 核心還原特色

### 1. 1:1 大宇 DAEWOO 低底盤公車 (12.0m x 2.5m x 3.2m)
* **經典外觀**：統聯客運招牌青蘋果綠塗裝 (`#148c3a`)、白色拉花飾條、大宇經典三橫柵鍍鉻水箱罩與大曲面擋風玻璃。
* **動態 LED 看板**：車頭與車尾真實發光點陣 LED，顯示「`81 經 公益路 臺中車站`」。
* **通透座艙與內裝**：
  * 右側安裝台灣專用 **寶錄電子 (Baolu) IC 卡刷卡機**（綠色液晶動態跳字）。
  * 走道兩側黃色安全立柱，每根立柱均配有 **紅色下車鈴按鈕**（按下會發光）。
  * 人體工學座椅與深藍色博愛座。
* **物理與可動機關**：
  * 前折疊門與中雙開外滑門獨立氣動開閉動畫。
  * 六輪轉動、前輪轉向、駕駛座方向盤隨動旋轉。
  * 車體煞車點頭與過彎內輪差懸吊傾斜。

### 2. 靈魂音效系統 (Web Audio API 原生合成)
* **悠遊卡 / 一卡通「BBB」刷卡聲**：
  * 普通卡：清脆單音 `1960Hz`「嗶~」（提示市民 10 公里免費）。
  * 學生票 / 愛心票：快速三連音「嗶、嗶、嗶」。
* **下車鈴**：經典雙音調「叮咚~」（E6 降至 C6）。
* **氣剎排氣聲**：大巴急煞與放鬆踏板時的壓縮空氣「嘶——哧！」排氣聲。
* **柴油引擎聲**：隨行駛時速與油門深度動態調頻的柴油重低音。
* **氣動車門與警示音**：開門排氣與關門前「嗶、嗶」安全提示音。
* **81路到站播音**：國台客英到站廣播。

### 3. 台中市 81路 真實路線與街景
* **5 大停靠站點**：
  1. `統聯轉運站 (站內)`
  2. `惠文高中 (公益路)`
  3. `草悟道 (市民廣場)`
  4. `臺中一中 (雙十路)`
  5. `臺中車站 (臺灣大道)`
* **台灣特色道路標線**：
  * 中央雙黃實線、路面白虛線。
  * 站牌前紅色標線與路面彩繪 **「公車停靠區」** 大字。
  * 十字路口斑馬線與 **黃色機車停等區**。
  * 台灣專屬 **小綠人行人倒數號誌燈**。
  * 騎樓街景建築與經典店家招牌（7-ELEVEN、全家便利店、50嵐珍奶、台中太陽餅老店）。

## 🎮 操作指南

| 鍵盤按鍵 | 功能說明 |
| :--- | :--- |
| **W** 或 **↑** | 前進加速 |
| **S** 或 **↓** | 煞車減速 / 倒車 |
| **A** / **D** 或 **←** / **→** | 方向盤左右轉向（具備大巴內輪差特性） |
| **Space** | 氣剎手煞車 |
| **1** | 開啟 / 關閉 **前門** |
| **2** | 開啟 / 關閉 **中門** |
| **B** | 觸發乘客 **悠遊卡/一卡通「逼逼」刷卡** |
| **L** | 按下 **「叮咚」下車鈴**（車頂鈴燈亮起） |
| **C** | 切換視角（駕駛室第一人稱 / 車外追蹤 / 客艙乘客） |
| **H** | 按喇叭 |
| **N** | 手動廣播下一站 |

*行動裝置或平板亦可使用畫面上的虛擬按鈕與觸碰鍵盤進行遊戲。*
